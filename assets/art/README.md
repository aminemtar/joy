# JOY artwork

`game_atlas.png` is an original AI-generated illustration atlas made for this project with the built-in image-generation tool. It contains 30 equal square cells, five columns by six rows, in the same order as `lib/catalog.dart`. The image is bundled locally; gameplay never calls an image service.

The app decodes the atlas once and draws the requested source rectangle. Keep the 5 × 6 layout if replacing it. The illustrated cards, introductions and memory-game faces all share this asset. Gameplay sprites are resolution-independent Canvas artwork in `lib/games/sprites.dart`.

## Generation prompt

The master app icon is `app_icon.png`, generated with the same built-in tool. `tool/build_app_icons.py` performs only standard size conversion for Android, iOS and web. To regenerate those sizes, install Pillow in your development environment and run `python tool/build_app_icons.py` from the project root.

### App icon prompt

Use case: logo-brand. Asset type: square mobile app icon for JOY, a playful offline two-player party-game collection. A premium polished 3D toy emblem: two interlocking rounded arcade gamepad halves, one cobalt blue and one coral pink, forming a compact dynamic friendly symbol around a small ivory lightning bolt in the center. Clear readable silhouette at tiny sizes; a few ivory controller-button details, no text or lettering, no trademark shapes. Solid deep navy #111C37 full-bleed square background, very subtle blue studio glow, beautiful bevels and soft highlights, centered large emblem with 16% safe padding. No extra frame, no outer rounded corners baked in, no watermark, no green. Match the glossy blue-and-coral illustrated 3D game assets of a modern premium mobile mini-game collection. Exactly square.
